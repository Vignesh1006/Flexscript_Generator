# 05 - Model from Spreadsheet

**Status:** PLANNED

## What it does
Builds the model from a sheet: Type, Name, X, Y, Z, RZ, Size, ConnectTo, SConnectTo. Re-runnable - existing names are updated, not duplicated.

## Example
180-row equipment list becomes a placed, named, connected model in about a minute.

## Delivery
Script + Excel template

## Install
See ..\README.md - same pattern for every tool. One .fsl per tool, never combined.
